# Visuals batch 1 — review only

44 PNG images and 44 self-contained animated HTML companions. Four composition variants per subject. Do not merge without visual review.

## Direction and provenance

Near-black graphite isometric scenes; mint for headless-kit, cyan for Agentroid, amber for BB 5th Coy Administration Portal, coral for Claude for HMOS Lite, violet for Microkernel Harness, blue for the conceptual lane diagram. Hero uses mint as its unifying accent. No humans or characters.

PNG art was generated from plain-language briefs with exact project names. Exports are normalized to the dimensions below. Each companion embeds its matching PNG and adds subtle CSS depth, light sweep, and SVG edge flow; it runs offline and honors `prefers-reduced-motion`. No browser was used; animation was checked statically rather than browser-tested.

Source material was limited to these checked-out repositories:

- [headless-kit README](https://github.com/Sohwhat6420/headless-kit/blob/3244597a084f7a5071c247e83bd69222ed862ee7/README.md) and its `tools/research/reddit-pull/docs/demo.svg` terminal illustration. Framed terminal snippets are generated redraws of that recorded demo, not a new dashboard or a claim of new measurements.
- Agentroid checkout `2f1a188`: `README.md`, `docs/media/demo-1.gif` (first frame: Calculator and MCP-client terminal), and `web/jobview/src/view/app.ts` inspected for context. Framed phone/terminal snippets are drawn from the README recording. No live web screenshot was captured and no job-view dashboard is claimed.
- BB 5th Coy Administration Portal, Claude for HMOS Lite, and Microkernel Harness are abstract product scenes: their source was unavailable. No project UI, data or feature claims are shown.
- Agentroid architecture is a conceptual explanation of the AI agent → MCP → local daemon (`bridged`) → adb → Android path and lease/look/tap/verify/receipt loop, with Preview status. It is not a benchmark result.
- headless-kit components are parts of one kit. `focus-gate` and `lane-mailbox` are requested by the brief but absent from this checkout; these elements are conceptual. Orchestrator/cloud/local lanes and mailbox likewise depict the requested conceptual workflow, not a measured deployed service.
